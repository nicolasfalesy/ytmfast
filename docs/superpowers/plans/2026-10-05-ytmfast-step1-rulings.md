# Step 1: decisions made during the build

Every ruling the build controller made while executing the step 1 plan, in order, each with what it costs if wrong. Parked review findings at the end are known, deliberate gaps for step 2.

- Ruling R1: SessionStore and Resolver use the `async-trait` crate so they work as Arc<dyn …> — why: the plan uses both as trait objects — cost if wrong: trivial swap to BoxFuture later.
- Ruling R2: Resolver gets a second method `resolve_fresh(&self, video_id) -> Result<Stream, Error>` that skips the link cache; relink uses it — why: spec says an expired link mid-song fetches a new one — cost if wrong: one extra trait method.
- Ruling R3: T1 stubs `play` and `daemon` (print "not built yet", exit 1); T3 wires import-session; T7 wires `play` (resolve -> TrackBuffer -> AudioPlayer+PipeWireSink, exit on Ended); T9 wires `daemon` — why: each task wires what it owns — cost if wrong: none.
- Ruling R4: CI runs in an `archlinux:latest` container (pacman: rust clang pkgconf pipewire opus sqlite ffmpeg) instead of ubuntu apt — why: matches the target system, avoids old libpipewire — cost if wrong: slower CI image pull.
- Ruling R5: implementers skip every live-check step and every step touching the real session, keyring, speakers, systemd units or pear-desktop; the controller runs those itself (T2, T3 s5, T5 s7, T7 s6, T9 s5, T10 s5, T11) — why: user's account, speakers and desktop; helpers must not touch them — cost if wrong: controller time only.
- Ruling R6: no error message, log line or Display output may contain a URL — every reqwest error goes through `.without_url()` (or a fixed message) before it becomes an Error — why: signed stream links carry access tokens (Global Constraints) — cost if wrong: less detail in errors.
- Ruling R7: `net::allowed_host` stays strict (https + allowlist). Production code checks it on every URL it builds or receives (API base constants, stream URLs, redirects); tests inject a local http base URL through the constructor, which is the only bypass — why: wiremock is http — cost if wrong: a caller forgetting the check; reviewers check each caller.
- Ruling R8: LICENSE keeps "Copyright (c) 2026 nicolasfalesy" — why: identical to the public widget repo's LICENSE and the repo URL already shows the handle — cost if wrong: one-line change.
- Ruling R9: Task 2 (pear baseline) is run by the controller now (music out loud per the user's pick); power numbers deferred until the user unplugs after Task 10 (user's pick).
- Ruling R10: Task 4 applies Set-Cookie only from responses whose host is youtube.com/google.com or a subdomain (never googlevideo.com) — why: reviewer T3 minor 2, keeps the stored session small and scoped — cost if wrong: a missed rotation from another host, which Google doesn't send.
- Ruling R11: the one cold preprocess per player version runs with COLD_MEMORY_LIMIT 256 MiB / COLD_DEADLINE 15 s; every other solver call keeps 64 MiB / 5 s — why: measured cold needs 176-192 MiB and up to 5.5 s on E-cores, so the spec limits would never cache a player; malloc_trim returns RSS to ~15-19 MiB after — cost if wrong: a ~190 MiB spike once per player version (YouTube ships a new player about weekly).
- Ruling R12: Task 5 reviewer Minors 1 (cancelled resolve orphans yt-dlp's deno child) and 3 (player memo not cleared after own-path failure) are upgraded to Important and join fix round 1 — why: step 2 cancels resolves on every skip, and orphaned processes break the spec's "nothing runs when idle"; a stale memo makes every song pay the yt-dlp path for an hour — cost if wrong: a slightly bigger fix round.
- Ruling R13: retry count = first try + 5 retries (6 requests, using all five backoff waits 1,2,4,8,16 s) — why: the only reading where the brief's five waits all happen — cost if wrong: one extra request before giving up.
- Ruling R14: keep the opus 0.4 crate's bundled libopus (cmake added to CI) for now — why: works, statically linked, no wrapper to maintain; a system-libopus wrapper is a later micro-optimisation for the user to pick — cost if wrong: ~0.5 MB bigger binary.
- Ruling R15: volume is cubic (slider v -> v^3 on the stream's channel volumes) and node.description is added — why: matches PulseAudio/pavucontrol so mixers show the slider value — cost if wrong: one-line change.
- Ruling R16: Task 7 reviewer Minor 3 (sink write wakes ~1/ms while waiting for room) and Minor 4 (unknown duration skips seek clamp / AAC end trim) join fix round 1 as Important — why: lower power is a spec success criterion, and the seek clamp is Review Focus item 3 — cost if wrong: a bigger fix round.
- Ruling R17: step 1 keeps the oEmbed fallback for title/artist; step 2 takes song details from the WEB_REMIX queue (`next`) so the per-song oEmbed request disappears — why: TV answers carry no title — cost if wrong: one extra small request per song until step 2.
- Ruling R18: the length hint caps the end at hint + 1 s instead of trimming at the hint — why: the hint is whole seconds, trimming there could cut real music — cost if wrong: up to 1 s of padding silence on fMP4 tracks without a duration.
- Ruling R19: AudioEvent gains `Loading` and its Error variant carries crate::Error (not String) — why: stops a late Ended from the previous song ending the new one, and lets the engine report the error code — cost if wrong: plan text drift only.
- Ruling R20: commits keep whichever session line the session that made them had (the session restarted after the usage-limit stop); no amend — why: history rewriting a pushed branch for a trailer isn't worth it — cost if wrong: two session lines on one branch.
- Ruling R21: `status` counts as activity and restarts the idle clock (brief: every command) — why: an open panel asking for status means the user is looking, like today's widget which never idle-quits with the panel open; step 4's widget must use events, not poll — cost if wrong: an engine kept alive by a polling client.
- Ruling R22: the units keep Requires= and After=ytmfast.socket plus Description lines — why: the standard pairing for a socket-activated service; stops a hand-started service binding its own socket — cost if wrong: none.
- Ruling R23: SIGTERM/SIGINT handling (reviewer Minor 2) joins Task 9 fix round 1 as Important — why: `systemctl --user stop` and logout are the normal shutdown path, step 2 saves state on quit, and the self-bound socket should be cleaned — cost if wrong: a slightly bigger fix round.
- Ruling R24: MPRIS built on zbus directly instead of mpris-server; serve(&Bus, cmds, events, hub) — why: mpris-server only connects via the process-wide session bus, which blocks private-bus tests; zbus is already in the tree — cost if wrong: more hand-written MPRIS code to maintain.
- Ruling R25: MPRIS property reads are not activity; Stop maps to Pause; Position is the last event's value (up to 1 s old) — why: widgets poll Position, and the engine has no stop-and-unload in step 1 — cost if wrong: an MPRIS progress bar may tick in 1 s steps (deferred: extrapolate while playing).
